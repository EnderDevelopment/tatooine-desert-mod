# Tatooine Desert Mod

Explore the Tatooine desert with custom villages, Blaster weapons, and an economy system.

## Features

- Custom Tatooine desert biome
- Blaster weapons with unique properties
- Custom desert villages with unique structures
- Villager factions with specialized professions
- Economy system with Galactic Credits
- Quests and status effects

## Requirements

- Minecraft 1.26.3
- Fabric Loader 0.14.0 or later
- GeckoLib

## Installation

1. Download the mod JAR file.
2. Place it in your `mods` folder.
3. Launch Minecraft with Fabric.

## Usage

Once installed, the mod will automatically add the Tatooine desert biome, Blaster weapons, and other features to your world. Explore the new biome, interact with the custom villages, and engage in the economy system.

## Configuration

The mod does not have a configuration file. All settings are hardcoded within the mod.
